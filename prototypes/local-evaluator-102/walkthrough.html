Кто вправе принять local report?

Этот throwaway prototype проверяет state model из issue #102: local evaluator может сообщить результат сценария и exact commit, но только Platform ingress сопоставляет его с source snapshot от GitHub adapter. Попробуйте happy path и отказные ветки.

Важно: local report полностью контролируется участником. Accepted означает «evidence принято в Attempt», а не Verified и не доказательство честного локального исполнения.
