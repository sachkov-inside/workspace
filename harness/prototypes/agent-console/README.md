# PROTOTYPE — пульт агентов

Одноразовый прототип на ветке `prototype/agent-console`, не для `main`.

Вопрос: какой вид и какая структура артефактов позволяют владельцу контролировать работу агентов
сверху, не читая код.

Запуск из корня Workspace: `python3 harness/prototypes/agent-console/server.py`, затем
`http://127.0.0.1:4480/?variant=A` (варианты A, B, C; стрелки внизу или ← →).

Данные: живые агенты из `herdr agent list`, PR из `gh`, артефакты из `sample-artifacts/`.
Артефакты `platform-625` собраны из настоящей матрицы `docs/verification` и скриншотов platform;
сжатая спецификация и тексты сдачи написаны вручную как пример формата.
