# Тарифы и доступ через Telegram

**Результат.** Человек из Telegram-бота получает аккаунт и ровно те права, которые ему положены: тариф за курс, перенесённую подписку Tribute или купленное руководство. Он и владелец видят состав, источник и срок каждого права.

**Для кого.** Покупатели курса, прежние подписчики Tribute, покупатели отдельных руководств, владелец.

**Входит.** Каталог тарифов, назначение тарифа из любого источника, перенос Tribute, кабинет с правами и сроками, восстановление после сбоев.

**Не входит.** Публичная продажа подписок, автоматическое продление, реальный запуск на продакшене.

## Требования

| № | Требование | Как проверяем |
|---|---|---|
| REQ-01 | Покупка курса открывает тариф «Материалы + сообщество» без даты окончания | e2e двух приложений |
| REQ-02 | Подписчики Tribute переносятся с подтверждённым сроком, неизвестный срок не угадывается | сценарии импорта |
| REQ-03 | Истечение одного права не трогает другие | тесты границ |
| REQ-04 | Скрытый тариф нельзя купить обходом интерфейса | тесты API |
| REQ-05 | Сбой провайдера или повтор не дают двойной выдачи | сценарии сбоев |
| REQ-06 | Бан и отзыв держатся до явной команды владельца | сценарии модерации |
| REQ-07 | Кабинет понятен на телефоне и компьютере | снимки, **решает владелец** |
| REQ-08 | Сроки точны на границах суток и месяца | тесты времени |
