# Артефакты этапов и пульт агентов

**Результат.** По каждой задаче владелец за минуту видит итог любого этапа: что решили, что специфицировали, как нарезали, что сдали, что проверено и где посмотреть. Замечание к любому месту артефакта доходит до агента.

**Для кого.** Владелец; агенты Claude Code и Codex во всех репозиториях с харнессом.

**Входит.** Формат артефактов этапов, папка задачи, локальный пульт, связь с Plannotator, публикация итога в PR.

**Не входит.** Слежение за агентом во время работы, облачный сервис, CI-карточка (отдельный этап).

## Требования

| № | Требование | Как проверяем |
|---|---|---|
| REQ-01 | У каждого этапа свой артефакт: decisions, spec, breakdown, plan, delivery, handoff, review | тест формата |
| REQ-02 | Первый экран любого артефакта — обзор не длиннее экрана, детали ниже | проверка длины |
| REQ-03 | Факты сдачи (тесты, статусы требований, доказательства) лежат в JSON и показываются отдельно от рассказа агента | тест формата + просмотр |
| REQ-04 | Пульт показывает живых агентов, их задачи и артефакты задач | ручная проверка |
| REQ-05 | Отзыв владельца сохраняется в review.md и читается следующей сессией | сценарий передачи |
| REQ-06 | Видео и снимки не попадают в git | проверка харнесса |
